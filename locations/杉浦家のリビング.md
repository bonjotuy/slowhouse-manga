# 場所シート：杉浦家のリビング（母屋）

## 基本情報
- **正式名称**：杉浦家のリビング（母屋）
- **所在地**：気仙沼（co-ba・裏の家と同じエリア）
- **カテゴリー**：個人宅リビング（杉浦家）
- **コンセプト**：生活感あふれる、人が集まる家族の中心空間

## 内観詳細

### 家具・設備
| アイテム | 詳細 |
|---------|------|
| **こたつ** | 部屋中央。上にご飯（鍋・茶碗・箸立て）が並ぶ |
| **ソファ** | 花柄・大きめ。荷物が雑然と置かれている |
| **テレビ** | ソファ向かい側 |
| **掲示板** | 壁に貼りつけ。メモ・写真・お知らせがびっしり |
| **洗濯物** | 室内に洗濯物干し（衣類がかかっている） |
| **窓** | 大きめ、カーテン付き。外の光が入る |

### 特徴的な小物・アイテム
- こたつの上のご飯セット（鍋・茶碗・箸・お盆）
- 掲示板（写真・メモがびっしり貼られている）
- ソファの上の雑多な荷物
- 室内干しの洗濯物（生活感の象徴）
- 地球儀（棚の上）

## 漫画描写のポイント
- **生活感**：洗濯物・散らかったソファ・こたつのご飯が「家族が本当にここで生きている」感を演出
- **温かさ**：こたつを囲んで食事するシーンは「帰ってきた」感・家族的な温かさ
- **掲示板**：キャラクターの活動・思い出が貼られている→物語の伏線として使える
- **奥行き**：俯瞰アングルで部屋全体を見せると、生活の豊かさが伝わる
